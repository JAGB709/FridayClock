# Panel web + despertador — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una web en el homelab (móvil primero) para ver el estado del reloj, gestionar alarmas con opciones propias y cambiar los ajustes, aplicando los cambios en el reloj al pulsar Guardar.

**Architecture:** El reloj (app Android `com.jarvis.clock`) sigue siendo la fuente de verdad y gana API nueva: `GET/PUT /settings`, `update` de alarmas con opciones por alarma, y `/sounds`. Un servicio nuevo `homelab/friday-panel` (FastAPI) sirve una web estática sin build y hace de proxy hacia el reloj con el token guardado en el homelab. La skill de Hermes y su reloj de mentira se amplían con lo mismo.

**Tech Stack:** Kotlin 1.9 + framework Android (sin dependencias), JUnit 4 + org.json en tests; Python 3.12, FastAPI, httpx, uvicorn, pytest; HTML/CSS/JS sin librerías.

**Spec:** `docs/superpowers/specs/2026-10-02-panel-web-design.md`

## Global Constraints

- Docs, comentarios, mensajes de error y UI en **español**.
- App: **cero dependencias de runtime** (framework + Kotlin stdlib). `minSdk 26`, `targetSdk 34`. Nada de AppCompat/OkHttp/Compose.
- Las alarmas **nunca** dependen de red ni del homelab; un sonido que falla cae al tono por defecto y luego a pitidos.
- Secretos (`CLOCK_TOKEN`, `PANEL_PASSWORD`) solo por entorno/`.env`; nunca en el código ni en respuestas al navegador.
- Capacidad nueva del reloj ⇒ `Actions` + `Api.kt` + skill (`clock.py`, `clock_tools.py`, `SKILL.md`, `mock_clock_server.py` + tests) + tabla de la API del README.
- Panel: escucha en `PANEL_BIND` (defecto `127.0.0.1`), puerto `PANEL_PORT` (defecto `8770`); timeout al reloj `CLOCK_TIMEOUT_S` (defecto `5`).
- Sonidos: extensiones `mp3`, `ogg`, `wav`, `m4a`; máximo **5 MB**.
- Rangos de opciones por alarma: `max_volume` 1–100, `ramp_s` 0–600, `snooze_min` 1–60; `null` = ajuste general.
- Comandos: `./gradlew testDebugUnitTest` (app), `cd hermes-skill && pytest -q`, `cd homelab/friday-panel && pytest -q`.

## Review Focus

1. **Alarma con un sonido subido que luego se borra o está corrupto** → debe sonar el tono por defecto (o pitidos), nunca silencio. Test de `Sounds.fileFor` (Task 4) + comprobación manual (Task 9).
2. **Alarmas guardadas antes de este cambio** (sin claves nuevas) → se leen igual, con opciones `null`. Test en Task 1.
3. **Reloj apagado o colgado** → el panel responde `502 "El reloj no responde"` dentro del timeout, sin colgar la web. Test en Task 6.
4. **Valores con tipo raro desde el móvil** (`5.5` o `"5"` para un entero, `"true"` para un bool) → `400` con el error por campo y **sin cambiar nada**. Tests en Task 2 y Task 1.
5. **Nombre de archivo malicioso al subir** (`../../x.mp3`, `a b?.MP3`, sin extensión) → saneado o rechazado; nunca se escribe fuera de `filesDir/sounds`. Tests en Task 4 y Task 6.

```kotlin
    /**
     * Copia con los campos de [p] aplicados (lo que usa `update` de la API).
     * Campo ausente = sin cambios; null en una opción = volver al ajuste general.
     * Lanza IllegalArgumentException con un mensaje en español si algo no vale.
     */
    fun withPatch(p: JSONObject): Alarm {
        var a = this
        if (p.has("time")) {
            val (h, m) = parseTime(p.optString("time")) ?: throw IllegalArgumentException("time debe ser HH:MM")
            a = a.copy(hour = h, minute = m)
        }
        if (p.has("label")) {
            val l = (p.opt("label") as? String)?.trim().orEmpty()
            require(l.isNotEmpty() && l.length <= 40) { "label debe tener entre 1 y 40 caracteres" }
            a = a.copy(label = l)
        }
        if (p.has("days")) a = a.copy(days = parseDays(p.opt("days")))
        if (p.has("enabled")) {
            a = a.copy(enabled = p.opt("enabled") as? Boolean ?: throw IllegalArgumentException("enabled debe ser true o false"))
        }
        return a.withOptions(p)
    }

    /** Solo las opciones por alarma de [p]; ignora hora, nombre, días y activa. */
    fun withOptions(p: JSONObject): Alarm {
        var a = this
        if (p.has("sound")) a = a.copy(sound = optSound(p))
        if (p.has("max_volume")) a = a.copy(maxVolume = optIntIn(p, "max_volume", 1, 100))
        if (p.has("ramp_s")) a = a.copy(rampSeconds = optIntIn(p, "ramp_s", 0, 600))
        if (p.has("snooze_min")) a = a.copy(snoozeMinutes = optIntIn(p, "snooze_min", 1, 60))
        if (p.has("briefing")) {
            a = a.copy(
                briefing = if (p.isNull("briefing")) null
                else p.opt("briefing") as? Boolean ?: throw IllegalArgumentException("briefing debe ser true, false o null")
            )
        }
        return a
    }

    /** Las pospuestas suenan igual que la alarma de la que vienen. */
    fun withOptionsOf(o: Alarm) = copy(
        sound = o.sound, maxVolume = o.maxVolume, rampSeconds = o.rampSeconds,
        snoozeMinutes = o.snoozeMinutes, briefing = o.briefing,
    )
```

```kotlin
        fun parseTime(s: String): Pair<Int, Int>? {
            val m = Regex("^(\\d{1,2})[:.h](\\d{2})$").find(s.trim()) ?: return null
            val h = m.groupValues[1].toInt()
            val mi = m.groupValues[2].toInt()
            return if (h in 0..23 && mi in 0..59) h to mi else null
        }

        private fun optIntIn(p: JSONObject, key: String, min: Int, max: Int): Int? {
            if (p.isNull(key)) return null
            val d = (p.opt(key) as? Number)?.toDouble()
            if (d == null || d % 1.0 != 0.0) throw IllegalArgumentException("$key debe ser un número entero")
            require(d >= min && d <= max) { "$key debe estar entre $min y $max" }
            return d.toInt()
        }

        private fun optSound(p: JSONObject): String? {
            if (p.isNull("sound")) return null
            val s = (p.opt("sound") as? String)?.trim().orEmpty()
            require(s.startsWith("system:") || s.startsWith("file:")) { "sound debe empezar por system: o file:" }
            return s
        }
```

```kotlin
package com.jarvis.clock

import org.json.JSONArray
import org.json.JSONObject

/**
 * Ajustes que se pueden leer y cambiar por la API (panel web, Hermes). Lista blanca:
 * token, puerto, bind y puente NO están, porque un error dejaría el reloj inaccesible.
 * La validación es pura (testeable en JVM); solo [apply] y [valuesJson] tocan Prefs.
 */
object SettingsSchema {

    enum class Type { INT, FLOAT, BOOL, STRING }

    class Field(
        val key: String,
        val type: Type,
        val group: String,
        val label: String,
        val min: Double = 0.0,
        val max: Double = 0.0,
        val maxLen: Int = 0,
        val get: () -> Any,
        val set: (Any) -> Unit,
    ) {
        fun problem(): String = when (type) {
            Type.INT -> "debe ser un entero entre ${min.toInt()} y ${max.toInt()}"
            Type.FLOAT -> "debe ser un número entre $min y $max"
            Type.BOOL -> "debe ser true o false"
            Type.STRING -> "debe ser un texto de 1 a $maxLen caracteres"
        }

        /** Valor normalizado (Int, Double, Boolean o String) o null si no vale. */
        fun coerce(raw: Any?): Any? = when (type) {
            Type.INT -> (raw as? Number)?.toDouble()?.takeIf { it % 1.0 == 0.0 && it in min..max }?.toInt()
            Type.FLOAT -> (raw as? Number)?.toDouble()?.takeIf { !it.isNaN() && it in min..max }
            Type.BOOL -> raw as? Boolean
            Type.STRING -> (raw as? String)?.trim()?.takeIf { it.isNotEmpty() && it.length <= maxLen }
        }
    }

    private const val G_ALARM = "Despertador"
    private const val G_SCREEN = "Pantalla"
    private const val G_VOICE = "Voz y asistente"
    private const val G_PLACE = "Ubicación"
```

```kotlin
import android.content.Context
import android.media.AudioAttributes
import android.media.MediaPlayer
import android.media.RingtoneManager

import org.json.JSONObject
import java.io.File

/**
 * Sonidos de alarma: tonos del sistema y archivos subidos (en filesDir/sounds, así
 * suenan sin red). Ids: "system:<uri>" o "file:<nombre>".
 */
object Sounds {
    private const val TAG = "Sounds"
    const val MAX_BYTES = 5 * 1024 * 1024
    private val EXTENSIONS = setOf("mp3", "ogg", "wav", "m4a")
    private val main = Handler(Looper.getMainLooper())
    private var previewPlayer: MediaPlayer? = null

    /** Nombre seguro para disco (solo [A-Za-z0-9_-] + extensión admitida) o null. */
    fun sanitizeName(raw: String): String? {
        val base = raw.substringAfterLast('/').substringAfterLast('\\').trim()
        val ext = base.substringAfterLast('.', "").lowercase()
        if (ext !in EXTENSIONS) return null
        val stem = base.substringBeforeLast('.').replace(Regex("[^A-Za-z0-9_-]+"), "_").trim('_').take(60)
        return if (stem.isEmpty()) null else "$stem.$ext"
    }

    /** Archivo de un id "file:…" si existe en [dir]; null en cualquier otro caso. */
    fun fileFor(dir: File, id: String?): File? {
        if (id == null || !id.startsWith("file:")) return null
        val name = sanitizeName(id.removePrefix("file:")) ?: return null
        return File(dir, name).takeIf { it.isFile }
    }

    fun dir(ctx: Context): File = File(ctx.filesDir, "sounds").apply { mkdirs() }

    /** URI reproducible para [id], o null (=> el que llama usa el tono por defecto). */
    fun uri(ctx: Context, id: String?): Uri? = when {
        id == null -> null
        id.startsWith("system:") -> runCatching { Uri.parse(id.removePrefix("system:")) }.getOrNull()
        else -> fileFor(dir(ctx), id)?.let { Uri.fromFile(it) }
    }

    fun list(ctx: Context): JSONArray {
        val out = JSONArray()
        runCatching {
            val rm = RingtoneManager(ctx).apply { setType(RingtoneManager.TYPE_ALARM) }
            val c = rm.cursor
            while (c.moveToNext()) {
                val uri = rm.getRingtoneUri(c.position)
                out.put(JSONObject().put("id", "system:$uri").put("name", c.getString(RingtoneManager.TITLE_COLUMN_INDEX)).put("kind", "system"))
            }
        }.onFailure { Log.w(TAG, "Sin tonos del sistema", it) }
        dir(ctx).listFiles()?.sortedBy { it.name }?.forEach {
            out.put(JSONObject().put("id", "file:${it.name}").put("name", it.name).put("kind", "file").put("size", it.length()))
        }
        return out
    }

    /** Guarda un sonido subido y comprueba que se puede reproducir. Devuelve su id. */
    fun save(ctx: Context, rawName: String, bytes: ByteArray): String {
        val name = sanitizeName(rawName) ?: throw IllegalArgumentException("nombre no válido: usa mp3, ogg, wav o m4a")
        require(bytes.isNotEmpty()) { "archivo vacío" }
        require(bytes.size <= MAX_BYTES) { "el sonido supera 5 MB" }
        val f = File(dir(ctx), name)
        f.writeBytes(bytes)
        val playable = runCatching { MediaPlayer().apply { setDataSource(f.path); prepare(); release() } }.isSuccess
        if (!playable) {
            f.delete()
            throw IllegalArgumentException("el reloj no puede reproducir ese archivo")
        }
        return "file:$name"
    }

    fun delete(ctx: Context, name: String): Boolean {
        val f = fileFor(dir(ctx), "file:$name") ?: return false
        return f.delete()
    }

    /** Suena 5 s por el canal de alarma. false si hay una alarma sonando. */
    fun preview(ctx: Context, id: String?): Boolean {
        if (AlarmRingService.ringing) return false
        stopPreview()
        val uri = uri(ctx, id)
            ?: RingtoneManager.getActualDefaultRingtoneUri(ctx, RingtoneManager.TYPE_ALARM)
            ?: RingtoneManager.getDefaultUri(RingtoneManager.TYPE_ALARM)
        val mp = MediaPlayer()
        return try {
            mp.setAudioAttributes(AudioAttributes.Builder().setUsage(AudioAttributes.USAGE_ALARM).build())
            mp.setDataSource(ctx, uri)
            mp.prepare()
            mp.start()
            previewPlayer = mp
            main.postDelayed({ stopPreview() }, 5_000)
            true
        } catch (e: Exception) {
            Log.w(TAG, "Preescucha fallida", e)
            mp.release()
            throw IllegalArgumentException("no se pudo reproducir el sonido")
        }
    }

    fun stopPreview() {
        main.removeCallbacksAndMessages(null)
        previewPlayer?.let { runCatching { it.stop() }; it.release() }
        previewPlayer = null
    }
}
```

```python
    return None

        body = json.dumps(obj).encode()
        self.send_response(code)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

        return self.headers.get("X-Auth-Token") == TOKEN

    def _raw(self) -> bytes:
        n = int(self.headers.get("Content-Length", 0))
        return self.rfile.read(n) if n else b""

    def _read(self) -> dict:
        raw = self._raw()
        return json.loads(raw or b"{}")

    def _path(self) -> str:
        return urlparse(self.path).path

    def _query(self) -> dict:

            return self._send(401, {"ok": False, "error": "token inválido"})

        if self._path == "/settings":
```

```python
"""
friday-panel: panel web del despertador Friday (móvil primero).

Sirve la web de static/ y hace de proxy hacia la API HTTP del reloj. El token del
reloj vive solo aquí (entorno/.env); el navegador nunca lo ve. No guarda estado:
el reloj es la fuente de verdad.

    CLOCK_URL=http://100.x.y.z:8080 CLOCK_TOKEN=... python app.py
"""

from __future__ import annotations

import hashlib
import hmac
import os
from dataclasses import dataclass
from pathlib import Path
from urllib.parse import quote

import httpx
from fastapi import Body, FastAPI, Request
from fastapi.responses import JSONResponse
from fastapi.staticfiles import StaticFiles

STATIC = Path(__file__).parent / "static"
MAX_SOUND_BYTES = 5 * 1024 * 1024
SOUND_EXTS = {".mp3", ".ogg", ".wav", ".m4a"}
COOKIE = "friday_panel"
COOKIE_MAX_AGE = 30 * 24 * 3600

# Acciones rápidas de Inicio -> (ruta del reloj, cuerpo).
QUICK_ACTIONS = {
    "stop": ("/alarm", {"action": "stop"}),
    "snooze": ("/alarm", {"action": "snooze"}),
    "test": ("/timer", {"seconds": 10, "label": "Prueba de alarma"}),
    "briefing": ("/briefing", {}),
}


@dataclass
class Config:
    clock_url: str
    clock_token: str
    password: str = ""
    timeout_s: float = 5.0

    @classmethod
    def from_env(cls) -> "Config":
        url = os.getenv("CLOCK_URL", "").rstrip("/")
        token = os.getenv("CLOCK_TOKEN", "")
        if not url or not token:
            raise SystemExit("Faltan CLOCK_URL o CLOCK_TOKEN en el entorno (.env)")
        return cls(url, token, os.getenv("PANEL_PASSWORD", ""), float(os.getenv("CLOCK_TIMEOUT_S", "5")))


def _session_value(password: str) -> str:
    """Valor de la cookie: derivado de la contraseña, nunca la contraseña."""
    return hmac.new(password.encode(), b"friday-panel-session", hashlib.sha256).hexdigest()


def _error(status: int, msg: str) -> JSONResponse:
    return JSONResponse({"ok": False, "error": msg}, status_code=status)


def create_app(cfg: Config) -> FastAPI:
    app = FastAPI(title="friday-panel", docs_url=None, redoc_url=None, openapi_url=None)

    async def clock(method: str, path: str, *, json: dict | None = None,
                    content: bytes | None = None, params: dict | None = None) -> JSONResponse:
        headers = {"X-Auth-Token": cfg.clock_token}
        if content is not None:
            headers["Content-Type"] = "application/octet-stream"
        try:
            async with httpx.AsyncClient(base_url=cfg.clock_url, timeout=cfg.timeout_s) as c:
                r = await c.request(method, path, json=json, content=content, params=params, headers=headers)
        except httpx.HTTPError:
            return _error(502, "El reloj no responde")
        if r.status_code == 401:
            return _error(502, "El token del reloj (CLOCK_TOKEN) no es válido")
        try:
            data = r.json()
        except ValueError:
            data = {"ok": r.is_success}
            if not r.is_success:
                data["error"] = f"El reloj respondió {r.status_code}"
        if not isinstance(data, dict):
            data = {"ok": r.is_success, "data": data}
        return JSONResponse(data, status_code=r.status_code)

    @app.middleware("http")
    async def require_login(request: Request, call_next):
        if cfg.password and request.url.path.startswith("/api/"):
            given = request.cookies.get(COOKIE, "")
            if not hmac.compare_digest(given, _session_value(cfg.password)):
                return JSONResponse({"ok": False, "error": "Inicia sesión", "login_required": True}, status_code=401)
        return await call_next(request)

    @app.post("/login")
    async def login(body: dict = Body(default_factory=dict)):
        if not cfg.password:
            return {"ok": True}
        if not hmac.compare_digest(str(body.get("password", "")), cfg.password):
            return _error(401, "Contraseña incorrecta")
        resp = JSONResponse({"ok": True})
        resp.set_cookie(COOKIE, _session_value(cfg.password), max_age=COOKIE_MAX_AGE, httponly=True, samesite="strict")
        return resp

    @app.get("/health")
    async def health():
        r = await clock("GET", "/health")
        return {"ok": True, "clock": r.status_code == 200}

    @app.get("/api/status")
    async def status():
        return await clock("GET", "/status")

    @app.get("/api/alarms")
    async def list_alarms():
        return await clock("GET", "/alarms")

    @app.post("/api/alarms")
    async def create_alarm(body: dict = Body(...)):
        return await clock("POST", "/alarm", json={**body, "action": "set"})

    @app.put("/api/alarms/{alarm_id}")
    async def update_alarm(alarm_id: int, body: dict = Body(...)):
        return await clock("POST", "/alarm", json={**body, "action": "update", "id": alarm_id})

    @app.delete("/api/alarms/{alarm_id}")
    async def delete_alarm(alarm_id: int):
        return await clock("POST", "/alarm", json={"action": "cancel", "id": alarm_id})

    @app.get("/api/settings")
    async def get_settings():
        return await clock("GET", "/settings")

    @app.put("/api/settings")
    async def put_settings(body: dict = Body(...)):
        return await clock("PUT", "/settings", json=body)

    @app.get("/api/sounds")
    async def list_sounds():
        return await clock("GET", "/sounds")

    @app.post("/api/sounds")
    async def upload_sound(request: Request, name: str):
        if Path(name).suffix.lower() not in SOUND_EXTS:
            return _error(400, "Formato no admitido: usa mp3, ogg, wav o m4a")
        if int(request.headers.get("content-length") or 0) > MAX_SOUND_BYTES:
            return _error(413, "El sonido supera 5 MB")
        data = await request.body()
        if not data:
            return _error(400, "Archivo vacío")
        if len(data) > MAX_SOUND_BYTES:
            return _error(413, "El sonido supera 5 MB")
        return await clock("POST", "/sounds", content=data, params={"name": name})

    @app.delete("/api/sounds/{name}")
    async def delete_sound(name: str):
        return await clock("DELETE", f"/sounds/{quote(name, safe='')}")

    @app.post("/api/sounds/preview")
    async def preview_sound(body: dict = Body(default_factory=dict)):
        return await clock("POST", "/sounds/preview", json=body)

    @app.post("/api/do/{action}")
    async def quick_action(action: str, body: dict = Body(default_factory=dict)):
        if action == "speak":
            text = str(body.get("text", "")).strip()
            if not text:
                return _error(400, "Escribe qué quieres que diga")
            return await clock("POST", "/speak", json={"text": text})
        if action not in QUICK_ACTIONS:
            return _error(404, f"acción desconocida: {action}")
        path, payload = QUICK_ACTIONS[action]
        return await clock("POST", path, json=payload)

    # La web, al final para que no tape /api.
    app.mount("/", StaticFiles(directory=STATIC, html=True), name="static")
    return app


def main() -> None:
    import uvicorn

    cfg = Config.from_env()
    uvicorn.run(create_app(cfg), host=os.getenv("PANEL_BIND", "127.0.0.1"), port=int(os.getenv("PANEL_PORT", "8770")))


if __name__ == "__main__":
    main()
```

```js
// ------------------------------------------------------------------ utilidades

function h(tag, attrs = {}, ...kids) {
  const el = document.createElement(tag);
  for (const [k, v] of Object.entries(attrs)) {
    if (k.startsWith("on")) el.addEventListener(k.slice(2), v);
    else if (k === "class") el.className = v;
    else if (k === "checked" || k === "value" || k === "disabled" || k === "selected") el[k] = v;
    else if (v !== false && v != null) el.setAttribute(k, v === true ? "" : v);
  }
  for (const kid of kids.flat()) {
    if (kid == null || kid === false) continue;
    el.append(kid instanceof Node ? kid : document.createTextNode(String(kid)));
  }
  return el;
}

async function api(method, path, body, raw) {
  const opt = { method, headers: {}, credentials: "same-origin" };
  if (raw !== undefined) { opt.body = raw; opt.headers["Content-Type"] = "application/octet-stream"; }
  else if (body !== undefined) { opt.body = JSON.stringify(body); opt.headers["Content-Type"] = "application/json"; }
  let res;
  try { res = await fetch(path, opt); } catch {
    return { ok: false, status: 0, data: { error: "Sin conexión con el panel" } };
  }
  const data = await res.json().catch(() => ({}));
  if (res.status === 401 && data.login_required) { showLogin(); }
  if (res.status === 502) setConn(false); else if (res.ok) setConn(true);
  return { ok: res.ok && data.ok !== false, status: res.status, data };
}

const errText = (r) => r.data.error || `Error ${r.status}`;

// Si hace falta login, la pantalla de login manda: no la tapamos con un error.
function showError(r) {
  if (r.data.login_required) return;
  view.replaceChildren(h("div", { class: "card bad" }, errText(r)));

function confirmInPage(msg, okLabel = "Aceptar") {

const daysText = (days) => {
  const set = new Set(days || []);

// ------------------------------------------------------------------ formulario y Guardar

function startForm(original, onSave, isNew = false) {
  form = { original: structuredClone(original), current: structuredClone(original), onSave, isNew, errors: {} };
  updateSaveBar();
  return form;
}

function setField(key, value) {
  if (!form) return;
  form.current[key] = value;
  updateSaveBar();
}

function changes() {
  if (!form) return {};
  const out = {};
  for (const k of Object.keys(form.current)) {
    if (JSON.stringify(form.current[k]) !== JSON.stringify(form.original[k])) out[k] = form.current[k];
  }
  return out;
}

const dirty = () => !!form && (form.isNew || Object.keys(changes()).length > 0);

function updateSaveBar() { $("#savebar").hidden = !dirty(); }

$("#save").addEventListener("click", async () => {
  if (!form) return;
  const b = $("#save");
  b.disabled = true; b.textContent = "Guardando…";
  const r = await form.onSave(form.isNew ? form.current : changes());
  b.disabled = false; b.textContent = "Guardar";
  if (r.ok) {
    toast("✓ Aplicado en el reloj");
    form = null; updateSaveBar();
    render(r.next || route);
  } else {
    const errs = r.data.errors || {};
    const detail = Object.entries(errs).map(([k, v]) => `${k}: ${v}`).join(" · ");
    toast(errText(r) + (detail ? ` — ${detail}` : ""), true);
    if (form) { form.errors = errs; markErrors(); }
  }
});

$("#discard").addEventListener("click", () => { form = null; updateSaveBar(); render(route); });

function markErrors() {
  document.querySelectorAll("[data-key]").forEach((el) => {
    const msg = form && form.errors[el.dataset.key];
    el.classList.toggle("error", !!msg);
    el.querySelector(".err")?.remove();
    if (msg) el.append(h("div", { class: "err" }, msg));
  });
}

async function go(next) {
  if (dirty() && !(await confirmInPage("Tienes cambios sin guardar. ¿Descartarlos?", "Descartar"))) return;

}

function optionNumber(key, label, min, max, unit, fallback) {
  const general = form.current[key] == null;
  const input = h("input", {
    type: "number", min, max, step: "1", inputmode: "numeric",
    value: general ? "" : form.current[key], disabled: general,
    oninput: (ev) => { if (ev.target.value !== "") setField(key, Number(ev.target.value)); },
  });
  const check = h("input", {
    type: "checkbox", checked: general,
    onchange: (ev) => {
      input.disabled = ev.target.checked;
      if (ev.target.checked) { input.value = ""; setField(key, null); }
      else { input.value = fallback; setField(key, fallback); }
    },
  });
  return h("div", { class: "opt", "data-key": key },
    h("label", { class: "switch" }, h("span", {}, label), h("span", { class: "row" }, h("span", { class: "muted" }, "general"), check)),
    h("label", { class: "field" }, h("span", {}, `Valor (${min}–${max} ${unit})`), input));
}

function soundPicker(sounds, reload) {
  const known = new Set(sounds.map((s) => s.id));

      const f = ev.target.files[0];
      if (!f) return;
      if (f.size > 5 * 1024 * 1024) { toast("El sonido supera 5 MB", true); return; }

      if (!r.ok) { toast(errText(r), true); return; }
      toast("✓ Sonido subido al reloj");
      setField("sound", r.data.id);
      reload();
    } });
  return h("div", { class: "opt", "data-key": "sound" },
    h("label", { class: "field" }, h("span", {}, "Sonido"), select),
    cur != null && !known.has(cur) ? h("div", { class: "warn" }, "⚠ Ese sonido ya no está en el reloj: sonará el tono por defecto.") : null,
    h("div", { class: "row" },
      btn("▶ Escuchar 5 s", async () => {

      }, "small ghost"),

}

async function renderAlarmEdit(id) {
  const [ra, rs] = await Promise.all([api("GET", "/api/alarms"), api("GET", "/api/sounds")]);
  if (route.edit !== id) return;
  if (!ra.ok) { showError(ra); return; }

  const found = (ra.data.alarms || []).find((a) => a.id === id);
  if (!isNew && !found) { view.replaceChildren(h("div", { class: "card bad" }, "Esa alarma ya no existe.")); return; }
  const src = isNew ? NEW_ALARM : found;
  const fields = ["time", "label", "days", "enabled", "sound", "max_volume", "ramp_s", "snooze_min", "briefing"];
  const original = Object.fromEntries(fields.map((k) => [k, src[k] ?? NEW_ALARM[k]]));

    return { ...r, next: { tab: "alarms" } };
  }, isNew);
  const sounds = rs.ok ? rs.data.sounds || [] : [];

}

function settingInput(f) {
  const v = form.current[f.key];
  if (f.type === "bool") {
    return h("label", { class: "switch", "data-key": f.key }, h("span", {}, f.label),
      h("input", { type: "checkbox", checked: v, onchange: (ev) => setField(f.key, ev.target.checked) }));
  }
  const isNum = f.type === "int" || f.type === "float";
  const input = h("input", isNum
    ? { type: "number", min: f.min, max: f.max, step: f.type === "int" ? "1" : "any", inputmode: f.type === "int" ? "numeric" : "decimal", value: v,
        oninput: (ev) => { if (ev.target.value !== "") setField(f.key, Number(ev.target.value)); } }
    : { type: "text", maxlength: f.max_len, value: v, oninput: (ev) => setField(f.key, ev.target.value) });
  const range = isNum ? ` (${f.min}–${f.max})` : "";
  return h("label", { class: "field", "data-key": f.key }, h("span", {}, f.label + range), input);
}

async function renderSettings() {
  const [r, rs] = await Promise.all([api("GET", "/api/settings"), api("GET", "/api/sounds")]);
  if (route.tab !== "settings") return;
  if (!r.ok) { showError(r); return; }
  startForm(r.data.settings, (c) => api("PUT", "/api/settings", c));
  const groups = new Map();
  for (const f of r.data.schema) { if (!groups.has(f.group)) groups.set(f.group, []); groups.get(f.group).push(f); }
  const files = rs.ok ? (rs.data.sounds || []).filter((s) => s.kind === "file") : [];
  view.replaceChildren(
    ...[...groups].map(([g, fs]) => h("div", { class: "card" }, h("h2", {}, g), fs.map(settingInput))),
    h("div", { class: "card" }, h("h2", {}, "Sonidos subidos"),
      files.length ? files.map((s) => h("div", { class: "row between" },
        h("span", {}, `${s.name} · ${Math.round((s.size || 0) / 1024)} KB`),
        btn("Borrar", async () => {
          if (!(await confirmInPage(`¿Borrar ${s.name}? Las alarmas que lo usen sonarán con el tono por defecto.`, "Borrar"))) return;
          const r2 = await api("DELETE", `/api/sounds/${encodeURIComponent(s.name)}`);
          toast(r2.ok ? "✓ Sonido borrado" : errText(r2), !r2.ok);
          if (r2.ok && !dirty()) renderSettings();
        }, "small ghost"))) : h("p", { class: "muted" }, "Ninguno. Súbelos desde la ficha de una alarma.")),
  );
}
```
